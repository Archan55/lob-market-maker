# Data directories

`raw/` and `processed/` are intentionally empty in version control.

No proprietary or licensed dataset is downloaded by this project. Convert
external Level 2 data with a user-supplied adapter into the canonical schema
documented in the repository README, then place the result under `processed/`
or pass an explicit path in configuration.

Generated synthetic data is a deterministic functional demonstration, not
evidence of real-market profitability.
